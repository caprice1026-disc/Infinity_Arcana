# 天体領域アルカナ 第一集

大アルカナ22原型を天体の象徴で表したセットです。各カードの意味JSONには、象徴・物語、正位置・逆位置の解釈と助言、仕事・人間関係・創作・自己理解の内容を収録しています。

画像は既存の[共通テンプレート](../template/infinity-arcana-card-frame-wide-nameplate-v2.png)を入力に、imagegenスキルの組み込み画像生成ツールで一枚ずつ制作しました。表面の最終プロンプトは[image-prompts.json](image-prompts.json)、共通裏面は[back-prompt.txt](back-prompt.txt)に保存しています。天体は架空の物語の象徴であり、科学解説や未来の確約を意図するものではありません。

カードと画像は検証済みの`available`です。パックと領域は既存セットと同じ`draft`で、人手による公開承認の記録は作成していません。

## 共通裏面

22枚で[共通裏面PNG](card-celestial-arcana-vol-1-back-v1.png)を共有します。パックカバーにも同じ絵を使います。

## 配信画像の再生成

表面はリポジトリルートから次を実行します。対象は天体パックの22枚に限定され、画像台帳の寸法・バイト数・SHA-256も更新します。

```powershell
npm.cmd run assets:build:celestial
```

裏面の変換には次を使います。原寸PNGを変更した場合は、台帳の裏面とパックカバー両方の寸法・バイト数・SHA-256を更新してから検証してください。

```powershell
ffmpeg -y -loglevel error -i cards/celestial-arcana/card-celestial-arcana-vol-1-back-v1.png -frames:v 1 -vf scale=1024:1536:flags=lanczos -c:v libwebp -quality 90 apps/sites-lite/public/assets/cards/celestial-arcana-vol-1/back.webp
npm.cmd run validate:content
npm.cmd run content:quality
```
